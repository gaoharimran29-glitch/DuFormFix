# DUFormFix

**Search course options faster on the Delhi University examination portal.**

DUFormFix is a free, student-built Chrome extension that adds searchable inputs to course-selection dropdowns on the DU examination portal. Instead of manually scrolling through long dropdown lists, you can type and quickly find the option you need.

> **Disclaimer:** DUFormFix is an independent student project and is not affiliated with or endorsed by the University of Delhi.

## ✨ Features

- 🔎 Search dropdown options by typing.
- ⚡ Quickly find courses in long dropdown lists.
- 🎯 Select an option directly from the search results.
- 🧩 Works on supported course-selection pages.
- 🆓 Free to use.

## 📥 Installation

**No Git installation required!**

1. Download the latest ZIP from the [Releases page](../../releases/latest).
2. Extract the downloaded ZIP file.
3. Open Google Chrome and visit `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted `DUFormFix` folder containing `manifest.json`.

That's it! Open or refresh the supported DU examination course-selection page to use DUFormFix.

## 🛠️ Updating

1. Download the latest release ZIP.
2. Extract it into a new folder.
3. Open `chrome://extensions`.
4. Remove the previous DUFormFix installation and load the new folder using **Load unpacked**.

## 🔒 Privacy

DUFormFix is designed to enhance dropdowns locally in your browser. It does not require an account or a separate backend service.

Please review the source code before installation and avoid sharing screenshots or recordings containing your roll number or other personal information.
