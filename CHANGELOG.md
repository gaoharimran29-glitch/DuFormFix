# Changelog

All notable changes to DUFormFix are documented here.

## [0.2.0] - 2026-10-12

### Added

- Added a browser action popup showing that DUFormFix is installed and where it works.
- Added a notice when no dropdowns are available on the current page.

### Changed

- Improved support for examination forms that load dropdowns dynamically.
- Removed the no-dropdown notice when dropdowns become available.
- Updated the extension version to `0.2.0`.

## [0.1.0] - 2026-10-10

### Added

- Added searchable inputs for course-selection dropdowns on supported DU examination pages.
- Added direct selection of matching course options.
